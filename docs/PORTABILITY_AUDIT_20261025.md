## Пять согласованных исправлений

1. **Лимит ответа API.** Как в Blocks/Pipelines, настройки из окружения больше не задают `max_tokens`. Параметр отсутствует в JSON запроса всех ролей, включая Reviewer, повтор после обрезанного ответа и синхронную диагностику. Старый `QWEN_MAX_TOKENS` игнорируется. Явный лимит в программно созданном Settings поддерживается для совместимости, но платформенная точка входа его не использует. Проверка с диагностическим ограничением сервера 16384 теперь проходит; фактический лимит платформы неизвестен.
2. **Окружение воркеров.** Передаются HOME, USERPROFILE, HOMEDRIVE, HOMEPATH, TMPDIR, TEMP, TMP, APPDATA, LOCALAPPDATA. Как у Blocks, включены HF_HUB_OFFLINE, TRANSFORMERS_OFFLINE, HF_DATASETS_OFFLINE. Ключ и адрес API не наследуются. Проверка импорта пакета из пользовательского HOME проходит в родителе и ребёнке. Потоки остаются 2.
3. **Стандартная библиотека.** Валидатор допускает abc, types и numbers, как оба рабочих архива. Остальные ранее разрешённые импорты сохранены.
4. **Запись отчёта.** OSError при обновлении report.json не прерывает финализацию. Предупреждение сохраняется в памяти и один раз печатается в stderr с редактированием ключа. При запрете записи самого отчёта файл на диске закономерно остаётся прежним; обещания его обновления нет. Это не обход запрета на запись самого submission.csv или заполненного диска.
5. **Временное разбиение.** Если 80-й процентиль совпадает с самым ранним периодом, граница переносится на следующий существующий период. Повторяется проверка непустоты, целочисленных индексов, границ и отсутствия пересечений после автоматической замены split. Пример [1]×9+[2] исправлен с 0/10 на 9/1. Обычная граница и группировка одинаковых периодов сохранены.

## Дополнительные подтверждённые ограничения, без новых правок

- **joblib / loky:** передача функции верхнего уровня из динамически загруженного experiment.py в Parallel(n_jobs=2) заканчивается ModuleNotFoundError на generated_… и BrokenProcessPool. Повторено на Linux во всех трёх ZIP. Это условный сбой отдельного сгенерированного эксперимента, а не объяснение уникального отказа нашего ZIP. Регистрацию модуля убирать нельзя: она нужна для dataclass. Исправление сериализации не входит в согласованные пять пунктов.
- **URL с query или userinfo:** наш конфиг и Max отклоняют такой адрес до API; Blocks принимает. Обычные HTTP/HTTPS, оба официальных адреса и внутренний HTTP-прокси проходят. Реальный адрес платформы с query неизвестен. Проверку адреса в этой правке не меняли.
- **Данные вне каталога задачи:** все три архива отклоняют пути и symlink, разрешающиеся за пределами task directory. Вложенные каталоги внутри разрешены. Это общее ограничение, а не найденная новая регрессия.
- **Ранний результат Blocks:** Blocks сохраняет простой safety baseline раньше сложного обучения. У нас резерв по просьбе пользователя остаётся выключенным. Поэтому ненулевой скор Blocks не доказывает успешность каждого его LLM/ML этапа.

Сохранены бюджет 9900 секунд, reasoning low, 6 исполнителей × 2 потока, 10 попыток подготовки, FLAML/LightAutoML 900 секунд. Изменение лимита токенов не меняет общий дедлайн LLM и запусков.
