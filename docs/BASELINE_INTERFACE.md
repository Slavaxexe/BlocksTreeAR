# Интерфейс исходного baseline

Источник: неизменённый `vendor/baseline.py`. Это описание прочитанного кода;
сам агент локально не запускался и API не вызывался.

## Запуск

Текущий baseline принимает путь к Markdown-файлу первым позиционным аргументом:

```text
python vendor/baseline.py data/raw/regression/task.local.md
python vendor/baseline.py data/raw/classification/task.local.md
```

Если аргумент не передан, используется `task.md` в текущем каталоге.
Для сдачи платформа требует файл `solution.py` в корне ZIP.
Приведённые команды описывают интерфейс, но для выполнения ещё нужны
окружение с зависимостями и доступ к API организаторов.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `OPENAI_API_KEY` | Общий командный ключ от организаторов |
| `OPENAI_BASE_URL` | Базовый URL совместимого API, предоставленный организаторами |
| `OPENAI_MODEL` | Точный API-идентификатор предоставленной модели |

Клиент — `openai.AsyncOpenAI`, запросы идут через `chat.completions.create`.
Название переменных не означает, что требуется ключ OpenAI: здесь они используются
для доступа к выделенному совместимому API Qwen.
В исходном vendor baseline `OPENAI_MODEL` читается напрямую из окружения и обязателен.
По новой инструкции платформы он необязателен; наш `solution.py` использует
`qwen/qwen3.8-27b`, когда переменная отсутствует. Ключ и адрес берутся из окружения.
Пакет `python-dotenv` есть в списках зависимостей, но сам baseline `.env` не загружает.

## Работа инструмента

- Baseline запускает собственный MCP-сервер через `--mcp-server`.
- Единственный инструмент `run_python(code)` исполняет Python в новом процессе.
- Рабочий каталог инструмента — каталог Markdown-файла задачи.
- Переменные Python между вызовами не сохраняются; созданные файлы сохраняются.
- Таймаут одного запуска инструмента — 1 800 секунд.
- Возвращается JSON со `stdout`, `stderr`, `exit_code`; stdout и stderr обрезаются до последних 12 000 символов каждый.
- При таймауте возвращается сообщение об ошибке.
- Окружение дочернего Python задаётся явно: `PATH=os.defpath` и `PYTHONIOENCODING=utf-8`.
  API-ключ в этот дочерний процесс baseline не передаёт.
- Максимум 100 итераций обращений к LLM; параллельные вызовы инструментов отключены.
- Автоматической проверки `submission.csv` и общего трёхчасового таймера в этом коде нет.

## Результат

По текстам задач требуется `submission.csv` рядом с Markdown-файлом задачи:

- Регрессия: `id,site_eui`, 22 449 строк данных.
- Классификация: `id,attack_cat`, 41 166 строк данных.

CSV должен быть UTF-8, с запятой, без отдельного индекса. ID и порядок строк
должны совпадать с `test.csv`. Сам baseline лишь передаёт описание LLM и инструменты;
имя и схему результата получает из текста задачи.
