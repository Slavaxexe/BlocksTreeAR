Резерв вычисляется прежней формулой `min(time_budget * .15, experiment_timeout + 300, 1500)`: при этих параметрах ровно 1200 секунд. Перед трёхчасовым лимитом платформы также остаётся 20 минут.

Остальные настройки сохранены: reasoning low, 10 попыток подготовки, до 1000 поисковых узлов, резервный результат выключен, max_tokens не отправляется. Адрес, ключ и модель берутся из окружения. CLI-аргументы могут переопределять параметры точки входа; QWEN_TIMEOUT_SECONDS переопределяет таймаут API.

Производные бюджеты AutoML по прежним формулам: FLAML/LightAutoML — 675 секунд обучения (11 минут 15 секунд); AutoGluon — 1080 секунд обучения (18 минут), процесс до 1800 секунд (30 минут), с ограничением доступным бюджетом запуска. Базовые 15 минут поэтому не являются универсальным лимитом каждого AutoML-процесса.

Потоки задаются окружением библиотек и toolkit. Произвольный сгенерированный код всё ещё может явно запросить больше потоков: AST-валидатор не запрещает n_jobs=-1.

В Blocks/Pipelines исследователи данных — до двух отдельных агентов для анализа данных и предложений признаков. В нашем решении отдельного пула нет; часть анализа выполняется при подготовке. Новый пул не добавлялся.
