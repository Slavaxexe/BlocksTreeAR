# История проекта

Первоначальные исследования и результаты ранних проверок. Сохранены для справки;
могут описывать другие контракты, фиксированный набор моделей или уже удалённый цикл.
Исходные материалы оставлены без правок.

- `research_notes/` — заметки об аналогах, контрактах и поиске гипотез.
- `reports/` — первоначальный исследовательский отчёт.
- `qwen_smoke_test.json` — первый короткий запрос к API, 19.10.2026.
- `runs/before-search-2026-10-20/` — локальный архив прежних regression / classification
  baseline (start v2) и синтетической проверки (start v3). Файлы сохранены без
  преобразования; каталог исключён из git вместе с предсказаниями и логами.
  Просмотр: `python3 viewer.py history/runs/before-search-2026-10-20 --port 8766`.
- `runs/search-diagnostics-2026-10-20/` — первый прогон дерева классификации с
  отказом из-за двусмысленной инструкции реализатору и ошибкой обработки неизвестных
  категорий. Поиск продолжился и сохранил лидера; повторная проверка использует
  исправленную общую инструкцию. Каталог также локальный и исключён из git.
- `runs/batch10-diagnostics-2026-10-20/` — две сетевые неудачи до нод:
  таймаут запроса подготовки и ошибка соединения одного extractor’а. После них
  добавлен ограниченный повтор API. Изолированные implementation-probe / probe-fixed
  используют готовую preparation и ту же гипотезу node_007: уточнение допустимых
  вычислений внутри функций устранило отказ; повтор успешен с одного ответа Qwen.
  Архив локальный и исключён из git.

Рабочая документация: [архитектура](../docs/ARCHITECTURE.md),
[карта проекта](../PROJECT_MAP.md), [запуск](../README.md).

`runs/async-diagnostics-2026-10-20/before-timeout-message-fix/` — первая проверка
двух исполнителей: девять успешных экспериментов, SVR отменена разработчиком
после обнаружения пустой диагностики таймаута. Исходный report сохранён;
итоговые report / delta согласованы с фактическими finish, детали в DIAGNOSTIC.md.
Это диагностический архив, не завершённый поиск на десять измеренных результатов.

В том же архиве `timeout240/` хранит повтор готовых скриптов трёх тяжёлых нод с
лимитом 240 с, одновременно с тестами. `timeout240-pair/` — повтор двух
GradientBoosting отдельно от тестов для проверки времени при двух исполнителях:
оба успешны за 227–229 с, RMSE 40.576746. Первая проба завершилась таймаутами;
она сохранена как замер с параллельными проверками, без результата метрики.
Подготовка, split, гипотезы и код исходного прогона сохранены; меняется только
лимит в новых start и добавляется ссылка на исходную ноду. Новых API-вызовов нет.
Результаты — локальные finish.json / results.json; основной прогон не переписывается.

`runs/classification15-diagnostics-2026-10-20/before-duplicate-feedback-fix/` —
первая попытка классификации с лимитом 15: три успешные ноды, затем Baker дважды
предложил существующий pipeline. Статус partial / llm_error; Macro F1 лидера 0.589495.
Три score, split / хеши / родители, параллельность и 41 166 строк ответов проверены
независимо; детали в DIAGNOSTIC.md / verification.json. После этого диагностика
повторов стала адресной для всех предложений пары. Архив исключён из git.

В том же архиве `before-network-retry-extension/` — вторая попытка: три успешные
ноды, затем оба запроса Baker завершились ошибкой соединения. Macro F1 лидера
0.589213; LinearSVC автоматически исправлена после smoke. Все три score и ответы
проверены независимо. После этого добавлена третья HTTP-попытка с паузами 2 / 4 с
при сетевых ошибках; лимиты ноды / запуска и один JSON-repair сохранены.

`baker-context-probe/` в том же архиве — контроль только планирования, без обучения:
два запроса на старом снимке вернули одинаковые повторы; свежий снимок с RF-лидером
сразу дал допустимые RF 300 + OneHotEncoder и LogisticRegression. Сохранены контексты,
HTTP-тела без заголовков / ключа и результаты проверки. Снимки восстановлены из
фактических артефактов; детали и ограничения вывода — DIAGNOSTIC.md / summary.json.
