# Классификация SMS-сообщений

## Задача

Постройте модель бинарной классификации, которая по тексту SMS-сообщения определяет, является ли оно спамом. Одна строка соответствует одному сообщению на английском языке. Целевая переменная `message_class` принимает одно из двух значений: `ham` — обычное сообщение, `spam` — спам.

Классы несбалансированы: обычные сообщения встречаются чаще спама. Основная метрика — F1 для класса `spam`.

## Данные

Пути указаны относительно каталога этого Markdown-файла:

- `train.csv` — 4 459 строк с признаками и таргетом;
- `test.csv` — 1 115 строк с признаками без таргета;
- `data_dictionary.csv` — описание всех полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

В `train.csv` 3 столбца: 1 входной признак, идентификатор `id` и таргет
`message_class`. В `test.csv` 2 столбца: те же признаки и `id`, без таргета.
CSV используют UTF-8, запятую как разделитель и точку как десятичный разделитель.
Текстовые значения, содержащие запятые или кавычки, заключены в кавычки по правилам CSV.

Текст сообщения может содержать сокращения, числа, ссылки, знаки препинания и нестандартное написание слов.

## Описание полей

| Поле | Тип и роль | Описание и единицы измерения |
|---|---|---|
| `id` | Строковый идентификатор | Уникальный идентификатор строки |
| `message` | Текстовый признак | Текст SMS-сообщения на английском языке |
| `message_class` | Категориальный таргет | ham — обычное сообщение, spam — спам; целевая переменная |

Полное описание находится в `data_dictionary.csv`.

## Что предсказать

Для каждого `id` из `test.csv` необходимо предсказать класс `message_class`: `ham` или `spam`.

Основная метрика — **F1 класса spam**:

```python
f1_score(y_true, y_pred, pos_label="spam", average="binary", zero_division=0)
```

Большее значение лучше.
Ответы теста недоступны.

## Формат результата

Файл `submission.csv` в каталоге этого Markdown-файла: CSV в UTF-8,
разделитель — запятая, без дополнительного индекса, ровно два столбца:

```csv
id,message_class
```

Для каждого `id` из `test.csv` требуется одна строковая метка класса: `ham` или `spam`.
Пропуски, повторяющиеся `id`, значения вне списка допустимых классов
и изменение порядка строк недопустимы.
