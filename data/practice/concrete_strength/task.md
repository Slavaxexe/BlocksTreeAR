# Прочность бетонных образцов

## Задача

Постройте регрессионную модель, которая по составу бетонной смеси и возрасту образца оценивает его прочность на сжатие — `strength_mpa`. Одна строка соответствует одному испытанию бетонного образца.

Целевая переменная измеряется в **МПа**. Количества компонентов смеси указаны в килограммах на кубический метр, возраст образца — в днях.

## Данные

Пути указаны относительно каталога этого Markdown-файла:

- `train.csv` — 832 строки с признаками и таргетом;
- `test.csv` — 198 строк с признаками без таргета;
- `data_dictionary.csv` — описание всех полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

В `train.csv` 10 столбцов: 8 входных признаков, идентификатор `id` и таргет
`strength_mpa`. В `test.csv` 9 столбцов: те же признаки и `id`, без таргета.
CSV используют UTF-8, запятую как разделитель и точку как десятичный разделитель.
Текстовые значения, содержащие запятые или кавычки, заключены в кавычки по правилам CSV.

Образцы с одинаковым составом смеси находятся в одной выборке. В test представлены составы, отсутствующие в train.

## Описание полей

| Поле | Тип и роль | Описание и единицы измерения |
|---|---|---|
| `id` | Строковый идентификатор | Уникальный идентификатор строки |
| `cement` | Числовой признак | Цемент на кубометр смеси; кг/м³ |
| `slag` | Числовой признак | Доменный шлак на кубометр смеси; кг/м³ |
| `fly_ash` | Числовой признак | Зола уноса на кубометр смеси; кг/м³ |
| `water` | Числовой признак | Вода на кубометр смеси; кг/м³ |
| `superplasticizer` | Числовой признак | Суперпластификатор на кубометр смеси; кг/м³ |
| `coarse_aggregate` | Числовой признак | Крупный заполнитель на кубометр смеси; кг/м³ |
| `fine_aggregate` | Числовой признак | Мелкий заполнитель на кубометр смеси; кг/м³ |
| `age_days` | Числовой признак | Возраст образца на момент испытания; дни |
| `strength_mpa` | Числовой таргет | Прочность на сжатие; целевая переменная; МПа |

Полное описание находится в `data_dictionary.csv`.

## Что предсказать

Для каждой строки `test.csv` необходимо предсказать `strength_mpa` — прочность бетонного образца на сжатие в МПа.

Метрика оценки — **RMSE** на исходной шкале таргета:
`sqrt(mean((y_true - y_pred) ** 2))`. Меньшее значение лучше.
Ответы теста недоступны.

## Формат результата

Файл `submission.csv` в каталоге этого Markdown-файла: CSV в UTF-8,
разделитель — запятая, без дополнительного индекса, ровно два столбца:

```csv
id,strength_mpa
```

Для каждого `id` из `test.csv` требуется одно конечное числовое предсказание.
Пропуски, бесконечности и повторяющиеся `id` недопустимы.
Порядок строк должен совпадать с `test.csv`.
