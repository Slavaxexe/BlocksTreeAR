# Вероятность открытия банковского вклада

## Задача

Постройте модель бинарной классификации, которая по характеристикам клиента, параметрам маркетинговой кампании и экономическим показателям оценивает вероятность открытия срочного банковского вклада. Одна строка соответствует наблюдению о контакте с клиентом.

Целевая переменная `subscribed` принимает значение `1`, если клиент согласился открыть вклад, и `0` в противном случае. Классы несбалансированы: отказы встречаются значительно чаще согласий.

## Данные

Пути указаны относительно каталога этого Markdown-файла:

- `train.csv` — 32 974 строки с признаками и таргетом;
- `test.csv` — 8 214 строк с признаками без таргета;
- `data_dictionary.csv` — описание всех полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

В `train.csv` 21 столбец: 19 входных признаков, идентификатор `id` и таргет
`subscribed`. В `test.csv` 20 столбцов: те же признаки и `id`, без таргета.
CSV используют UTF-8, запятую как разделитель и точку как десятичный разделитель.
Текстовые значения, содержащие запятые или кавычки, заключены в кавычки по правилам CSV.

Значение `unknown` в категориальных столбцах означает неизвестное значение. В `pdays` значение `999` означает, что ранее с клиентом не связывались.

## Что предсказать

Для каждого `id` из `test.csv` необходимо предсказать вероятность класса `subscribed=1` — согласия клиента открыть вклад.

Основная метрика — **ROC AUC**:

```python
roc_auc_score(y_true, y_pred)
```

Большее значение лучше.
Ответы теста недоступны.

## Формат результата

Файл `submission.csv` в каталоге этого Markdown-файла: CSV в UTF-8,
разделитель — запятая, без дополнительного индекса, ровно два столбца:

```csv
id,subscribed
```

Для каждого `id` из `test.csv` требуется одна вероятность класса `1` в диапазоне от 0 до 1 включительно.
Пропуски, бесконечности, значения вне указанного диапазона и повторяющиеся `id` недопустимы.
Порядок строк должен совпадать с `test.csv`.
