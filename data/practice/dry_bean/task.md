# Определение сорта фасоли по геометрии семени

## Задача

Постройте модель многоклассовой классификации, которая по геометрическим характеристикам семени определяет сорт фасоли. Одна строка соответствует одному семени. Целевая переменная `bean_class` принимает одно из семи значений: `BARBUNYA`, `BOMBAY`, `CALI`, `DERMASON`, `HOROZ`, `SEKER`, `SIRA`.

Частоты классов различаются. Основная метрика — Macro F1, учитывающая качество классификации каждого сорта с одинаковым весом.

## Данные

Пути указаны относительно каталога этого Markdown-файла:

- `train.csv` — 10 883 строки с признаками и таргетом;
- `test.csv` — 2 728 строк с признаками без таргета;
- `data_dictionary.csv` — описание всех полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

В `train.csv` 18 столбцов: 16 входных признаков, идентификатор `id` и таргет
`bean_class`. В `test.csv` 17 столбцов: те же признаки и `id`, без таргета.
CSV используют UTF-8, запятую как разделитель и точку как десятичный разделитель.
Текстовые значения, содержащие запятые или кавычки, заключены в кавычки по правилам CSV.

Признаки представляют собой числовые характеристики формы семени. Изображения в состав данных не входят.

## Что предсказать

Для каждого `id` из `test.csv` необходимо предсказать класс `bean_class` (одна из семи строковых меток, перечисленных выше).

Основная метрика — **Macro F1** по семи классам:

```python
f1_score(y_true, y_pred,
         labels=["BARBUNYA", "BOMBAY", "CALI", "DERMASON", "HOROZ", "SEKER", "SIRA"],
         average="macro", zero_division=0)
```

Большее значение лучше.
Ответы теста недоступны.
