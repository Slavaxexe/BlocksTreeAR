# Почасовой спрос на прокат велосипедов

## Задача

Постройте регрессионную модель, которая по календарным и погодным характеристикам оценивает почасовой спрос на прокат велосипедов — `rental_count`. Одна строка соответствует одному часу работы системы проката.

Целевая переменная — общее число аренд за час. Погодные показатели относятся к тому же часу и считаются известными при оценке спроса.

## Данные

Пути указаны относительно каталога этого Markdown-файла:

- `train.csv` — 15 211 строк с признаками и таргетом;
- `test.csv` — 2 168 строк с признаками без таргета;
- `data_dictionary.csv` — описание всех полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

В `train.csv` 14 столбцов: 12 входных признаков, идентификатор `id` и таргет
`rental_count`. В `test.csv` 13 столбцов: те же признаки и `id`, без таргета.
CSV используют UTF-8, запятую как разделитель и точку как десятичный разделитель.
Текстовые значения, содержащие запятые или кавычки, заключены в кавычки по правилам CSV.

Train содержит наблюдения с января 2011 года по сентябрь 2012 года. Test содержит наблюдения за октябрь–декабрь 2012 года. Строки упорядочены по времени; некоторые часы в данных отсутствуют.

## Что предсказать

Для каждой строки `test.csv` необходимо предсказать `rental_count` — общее число аренд велосипедов за соответствующий час.

Метрика оценки — **RMSLE**:
`sqrt(mean((log1p(y_true) - log1p(y_pred)) ** 2))`.
Меньшее значение лучше. `log1p(x)` означает натуральный логарифм `1 + x`.
Ответы теста недоступны.

## Формат результата

Файл `submission.csv` в каталоге этого Markdown-файла: CSV в UTF-8,
разделитель — запятая, без дополнительного индекса, ровно два столбца:

```csv
id,rental_count
```

Для каждого `id` из `test.csv` требуется одно конечное неотрицательное числовое предсказание. Дробные значения разрешены.
Пропуски, бесконечности, отрицательные значения и повторяющиеся `id` недопустимы.
Порядок строк должен совпадать с `test.csv`.
