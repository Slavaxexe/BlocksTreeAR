# Supply Chain Management (мультитаргет)

## Задача

Постройте модель мультитаргетной регрессии, которая по характеристикам
цепочки поставок одновременно предсказывает 16 целевых переменных —
будущие цены компонентов в различные периоды времени.

Данные получены из Trading Agent Competition in Supply Chain Management
(TAC SCM) 2010 года. Каждая строка описывает состояние рынка в один
момент времени: индексы цен конкурентов, характеристики SKU, сегменты
спроса с лагами, стоимость хранения и процентные ставки.

## Данные

- `participants/train.csv` — 7,172 строки с признаками и 16 таргетами.
- `participants/test.csv` — 1,794 строки с признаками без таргетов.
- `meta.json` — метаданные датасета.

Источник: [OpenML (id=41486)](https://openml.org/d/41486)

## Описание таргетов

| Таргет | Описание |
|--------|----------|
| `LBL` | Цена в текущем периоде |
| `MTLp2A`–`MTLp16A` | Цены в периодах 2–16 |

## Метрика

Основная метрика — **средний RMSE** по всем 16 таргетам:

```
score = mean(RMSE(target_i) for i in 1..16)
```

Направление: **minimize** (меньше — лучше).
