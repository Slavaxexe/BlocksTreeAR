# HTTP-фикс из slava и платформенная сборка на 80 минут

22 октября 2026 перенесена обработка ошибок API из `slava`, коммит `34664b9e6f193e91f5d2d1e32fc16553c6cc5a97`. Перенесены функция `api_error_details` из `agent/qwen.py` и соответствующие ветви обработки ошибок и ожидания из `agent/agents.py`. Остальные изменения slava не объединялись с max.

- HTTP 429 временной перегрузки приводит к повтору после паузы, общей для всех ролей одного запуска. Уже отправленные запросы не отзываются.
- Поддержаны `Retry-After` в секундах и HTTP-дате, а также `retry-after-ms`. Если заголовка нет, используется возрастающая пауза.
- Исчерпание квоты/бюджета распознаётся отдельно; новые запросы всех ролей прекращаются. Успевшие сохраниться результаты остаются доступны.
- Ожидание ограничено общим дедлайном; отдельного API-запроса за само ожидание не списывается.
- Сырые тела ошибок провайдера не записываются; сохраняются тип, HTTP-код и безопасные служебные поля.

Поддержка внутреннего HTTP-прокси платформы в OPENAI_BASE_URL уже была в max и сохранена.

Четыре локальных теста HTTP-обработки прошли без сети и платных запросов: повтор после 429, форматы Retry-After, общий стоп квоты и дедлайн во время общей паузы.

## ZIP на 80 минут

Сборщик: `tools/build_platform.py`. Команда из корня проекта:

```powershell
uv run --locked python tools/build_platform.py "../Кейс+инструкция/max_solution_80min.zip"
```

Сборка превращает пакет agent в корневые max_*.py, обновляет импорты, команды дочерних процессов, шаблоны генерируемого кода и пути приложения. Предоставленный requirements.txt копируется без изменения. Ключи, .env, данные и артефакты в ZIP не включаются.

Только в платформенной сборке общий бюджет ограничен 4800 секундами (80 минут). CLI может уменьшить его, но не увеличить или отключить через 0. По умолчанию дочернему процессу отводится до 1200 секунд в пределах оставшегося общего времени; предусмотрены три версии кода блока. Параллелизм — 4 ML-ноды и 16 API-слотов. Число нод и запросов отдельно не ограничено. Исходный локальный CLI сохраняет прежние настройки времени.

Платформенные настройки HTTP по умолчанию: таймаут 180 секунд, 12288 токенов; окружение QWEN_TIMEOUT_SECONDS/QWEN_MAX_TOKENS имеет приоритет. При отсутствии OPENAI_MODEL используется qwen/qwen3.8-27b. Ключ и базовый URL подставляет платформа.

В распакованной сборке проверены плоская структура, неизменность requirements.txt, импорты и потолок бюджета (в том числе запрос 99999 секунд и значение 0). Два коротких запуска LightGBM/CatBoost через отдельный worker успешно выполнили сборку модулей, обучение, предсказания и временную запись submission. Полный 80-минутный прогон и Docker Boosters не запускались.
