# Запуск

Нужен Python 3.12. Из корня проекта:

```powershell
uv sync --locked
```

Скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY`.
Переменные окружения имеют приоритет над `.env`.

| Настройка | Значение по умолчанию |
| --- | --- |
| `OPENAI_BASE_URL` | `https://inference.airi.net/v1` |
| `OPENAI_MODEL` | `Qwen/Qwen3.8-27B` |
| `QWEN_TIMEOUT_SECONDS` | `90` |
| `QWEN_MAX_TOKENS` | `6144` |

Для Baker ожидание одного запроса составляет до 180 секунд; для остальных ролей
используется `QWEN_TIMEOUT_SECONDS`. Общий лимит времени имеет приоритет.
После двух таймаутов/временных ошибок API планирование переходит к одной гипотезе
за запрос с паузой 5 секунд перед повтором. Готовые ноды продолжают работу,
а подготовка и split сохраняются. После трёх неудачных циклов подряд планирование
останавливается, лучший полученный результат остаётся сохранённым.

Проверка заполненности настроек без запроса к API:

```powershell
uv run --locked python -m agent check-config
```

Запуск baseline и поиска гипотез:

```powershell
uv run --locked python solution.py data/regression/task.local.md
uv run --locked python solution.py data/classification/task.local.md
```

Эти команды обращаются к Qwen и исполняют сгенерированный Python-код.
Вместо сохранения ключа в `.env` можно добавить `--key-stdin`: программа запросит его при запуске.

По умолчанию весь проход ограничен 600 секундами, отдельный процесс — 240 секундами.
Параметры `--time-budget` и `--experiment-timeout` задаются в секундах.
`--output-dir` позволяет выбрать новый каталог для артефактов.

Поиск включает до 10 нод вместе с baseline, 3 параллельные ноды (2 improve и 1 explore),
до 8 одновременных обращений к Qwen и до 80 API-запросов суммарно вместе с исправлениями.
Число агентов не равно числу нод: каждую создаваемую/изменяемую часть пишет отдельный агент.
Например:

```powershell
uv run --locked python solution.py data/regression/task.local.md --max-experiments 10 --parallel 3 --parallel-agents 8 --max-llm-calls 80
```

Только первый baseline, без поиска новых гипотез:

```powershell
uv run --locked python -m agent baseline --task data/regression/task.local.md
```

Qwen анализирует результаты и предлагает следующие гипотезы с выбором родителя.
Нода реализует одну гипотезу. Baker задаёт порядок блоков, точные интерфейсы и
список `write_blocks`, который может содержать несколько новых или изменяемых модулей.
Уже в baseline он создаёт первые переиспользуемые блоки. Каждый реализатор получает
план сборки и пишет один блок `run(state) -> dict`; агенты работают параллельно.
Остальные блоки сборщик копирует из сохранённых нод. После готовности всех модулей
он собирает решение и выполняет цепочку по порядку. `experiment.py` создаёт Python.
На каждый блок до трёх версий кода, включая исправления ошибок полного запуска.
Общий предел 8 включает реализаторов, Baker, анализаторы и извлечение требований;
он настраивается через `--parallel-agents` отдельно от числа нод `--parallel`.
Следующие гипотезы запускаются после новых анализов, без ожидания остальных нод.
Общий scorer считает качество; контроллер сохраняет лучший ответ по validation.
Код и результаты всех попыток остаются в отдельных папках нод.

## Откуда берутся данные

Первый аргумент `solution.py` — путь к Markdown с заданием. Его каталог становится
корнем для относительных путей к данным. Например:

```text
solution.py data/regression/task.local.md
                  ↓
data/regression/train.csv
data/regression/test.csv
```

Имена файлов определяются из условия и инвентаризации каталога.
Контроллер сохраняет абсолютный `task_directory` в `preparation.json`.
Сгенерированный `load_data(task_directory, config)` читает входы через
`task_directory / config['data']['files'][role]`.

Для другой задачи достаточно передать другой Markdown. Папка не обязана называться
`data`, а файлы — `train.csv` и `test.csv`. Во время запуска данные не скачиваются.

Для локальных публичных задач используйте `task.local.md`: в нём пути соответствуют
файлам в той же папке. Оригинальный `task.md` сохранён без изменений.

Итоговый файл ответа записывается рядом с заданием. Артефакты эксперимента находятся
в `artifacts/` и исключены из Git вместе с локальными настройками и логами.

## Другие команды

Только извлечение условия:

```powershell
uv run --locked python -m agent extract --task data/regression/task.local.md
```

Просмотр сохранённых артефактов:

```powershell
uv run --locked python viewer.py
```

Просмотрщик доступен по адресу `http://127.0.0.1:8765` и не вызывает Qwen.
Во вкладке «Эксперименты» выберите ноду: сверху появится порядок её блоков,
источники версий, статусы агентов каждого блока и отметки исправлений. В деталях доступны код блоков, попытки
и выводы анализатора. Пунктир на графе показывает источники модулей выбранной ноды.
